# Mission Control settings

Optional. Only the frontmatter above is read. Every key can be left out.

- title: the name in the header. Default: MY PROJECTS
- folders: only read these folders, for example `folders: [Projects, Archive]`. Default: the whole folder
- links: `obsidian` or `none`. Default: obsidian when the folder has a .obsidian folder
- obsidianVault: the vault name in Obsidian links. Default: this folder's name
- out: where build.py writes the page, relative to this folder. Default: Mission Control.html
